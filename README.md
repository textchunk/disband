# Disband

Disband is a music toolkit for Windows that runs on your own PC. It uses the best open models available to pull songs apart and rework them.

- **Stem separation:** vocals, drums, bass, guitar, piano and the rest, saved as separate files
- **Vocals:** lead and backing vocals apart, or an instrumental for karaoke
- **Drums:** kick, snare, toms, hi-hat and cymbals as their own stems
- **Clean-up:** crowd noise removal, de-limiting, mono to stereo, and upscaling
- **Audio to MIDI:** a whole song, or a piano track, written down as MIDI
- **Conversion:** MP3, WAV, FLAC, AIFF, M4A and OGG, including sampler-style rates and bit depths

Drop files on the window, or right-click them in Explorer. Everything is saved to the folder you choose.

## Download

**[Get the latest version](https://github.com/textchunk/disband/releases/latest)** and run `Disband-Setup-<version>.exe`. The installer isn't signed yet, so Windows may show a warning: click "More info", then "Run anyway". After that, Disband updates itself.

Disband used to be called Stems. If you have Stems installed, it updates to Disband by itself and keeps your models and settings.

This repository holds the installers only.
