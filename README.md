# Disband

Split any song into its parts (vocals, drums, bass, guitar, piano and the rest) on Windows. Drop a song on the window and the stems are saved to your folder.

**[Download the latest version](https://github.com/textchunk/disband/releases/latest)** and run `Disband-Setup-<version>.exe`. Windows may warn that the installer isn't signed: click "More info", then "Run anyway". After that, Disband updates itself.

Disband used to be called Stems. If you have Stems installed, it updates to Disband by itself and keeps your models and settings.

This page holds the installers only.
